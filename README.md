# Lista de tareas

Aplicación web de gestión de tareas desarrollada con Angular y TypeScript como proyecto práctico para retomar el desarrollo frontend.

## Funcionalidades

- Crear tareas.
- Eliminar tareas.
- Marcar tareas como completadas o pendientes.
- Filtrar tareas por estado: todas, completadas y pendientes.
- Mostrar contadores de tareas totales, completadas y pendientes.
- Interfaz responsive adaptada a pantallas móviles.
- Controles con indicadores de foco y nombres accesibles.

## Tecnologías

- Angular
- TypeScript
- HTML
- CSS
- Git y GitHub

## Requisitos

- Node.js y npm compatibles con la versión de Angular utilizada.
- Git, para clonar el repositorio.

## Instalación y ejecución

1. Clona el repositorio:

   ```bash
   git clone https://github.com/OscarBayoRequena/-NG-Lista-de-tareas.git
   ```

2. Accede al directorio del proyecto:

   ```bash
   cd https://github.com/OscarBayoRequena/-NG-Lista-de-tareas.git
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Inicia el servidor de desarrollo:

   ```bash
   ng serve
   ```

5. Abre en el navegador la dirección que indique Angular CLI, normalmente `http://localhost:4200/`.

## Aprendizajes

Este proyecto permite practicar:

- Componentes standalone y plantillas de Angular.
- Interpolación y property/event binding.
- Renderizado de listas mediante `@for`.
- Uso de getters y métodos para gestionar y filtrar datos.
- Estilos CSS, Flexbox y media queries.
- Accesibilidad básica mediante atributos ARIA y navegación por teclado.
- Control de versiones con Git y publicación en GitHub.
